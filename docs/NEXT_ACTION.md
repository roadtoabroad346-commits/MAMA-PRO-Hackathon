# Следующий шаг

Сервер выбирает первое активное собственное обращение, иначе ближайшее будущее календарное событие. Никаких созданных «заказов» из демо. UI объясняет: проверить ответ, уточнить договорённость или подготовить вопросы к событию. Это организационная поддержка, не диагноз/прогноз.

Одна запись маркировки owner/source; complete, defer, edit text, hide/restore. Hidden сворачивает содержание, restore доступен. Переоткрытие не дублирует markers. Ручная отметка не изменяет request status и не создаёт appointment. Нет наград, streak, процентов здоровья, рейтингов детей и требований ежедневной активности. После закрытия обращения выбор вычисляется заново. Tests: next action isolation and no duplicate marker.
