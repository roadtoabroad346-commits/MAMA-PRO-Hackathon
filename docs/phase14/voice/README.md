# Полный озвученный прогон — 8 ноября 2026

Готовые файлы: [видео со слайдами и демо](FULL_VOICE_REHEARSAL_RU.mp4), [аудио](FULL_VOICE_REHEARSAL_RU.mp3), [текст](TRANSCRIPT.md), [точный тайминг](timeline.json).

**Формат: синтезированная русская речь eSpeak NG 1.51, ru, 145; слайды + ранее записанный фактический прогон production-сборки. Не выступление человека, не новое live-демо, не исследование с родителем.** Такая маркировка присутствует на всём видео. Роботизированный голос пригоден для технического прогона, естественность и произношение названия не подтверждаются.

Файл содержит весь текст сценария без обрезания реплик. Технические названия для произношения раскрыты словами, смысл не изменён. Речь не ускорялась после синтеза. В паузах остаётся время на действия и чтение экрана. Видео приложения не ускорено: начальная служебная загрузка убрана, в конце демо удерживается последний кадр до границы блока.

Временные блоки: 0:00–0:35 проблема; 0:35–0:55 идея; 0:55–3:15 демо; 3:15–3:50 доверие; 3:50–4:25 проверка; 4:25–4:50 доработка; 4:50–4:58 завершение. Номинальный бюджет остаётся 300 с; озвученный файл — 298 с. Конец последней реплики — 297,504 с, до жёсткого лимита 2,496 с. 12,858 с внутри демоблока не прибавляются повторно к общему запасу.

Длительность каждого исходного WAV измерена по PCM-сэмплам и проверена относительно своего окна; значения в timeline.json. Медиадлительность и полный decode проверены FFprobe/FFmpeg, результат voice_validation.json. Это измерение воспроизведения синтезированной речи, а не оценка по числу слов. Код генерации и монтажа сохранён рядом; зависимости инструмента находятся только в ignored work/, не в продукте.

**Закрыто:** полный синтетический озвученный вариант сценария с демо ≤300 с. **Остаётся NOT RUN:** голосовая репетиция реального выступающего и оператора на ноутбуке площадки; исследование с родителем; KK-редактура; ранее перечисленные ручные QA. P0/live NO-GO сохраняется.

Для воспроизведения кода генерации требуется локальный eSpeak NG 1.51 с русскими данными, FFmpeg, Python/PyMuPDF. В данной среде официальные Debian-пакеты espeak-ng, libespeak-ng1, espeak-ng-data, libpcaudio0, libsonic0 распакованы без установки в систему в work/voice-tools/root. Команды синтеза и параметры находятся в generate_voice.py; render_voice.py собирает семь сцен и добавляет маркировку. Путь запуска — корень репозитория.
