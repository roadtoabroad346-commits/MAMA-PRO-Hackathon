## Сбой

Не ждать переход дольше 5 секунд. Сказать: «Живой показ сейчас недоступен. Покажу запись того же синтетического прототипа; это не интерактивная сессия». Включить **FALLBACK_45s.mp4**, затем слайд 4. Резерв заменяет остаток демо и не добавляет 45 секунд к питчу. Если до конца демоблока осталось меньше 45 секунд — показать только сохранённый кадр статуса, прямо назвав его статическим, и перейти дальше вовремя.

При storage error: «Сохранение не подтверждено». Старый UUID из видео не существует автоматически в новом браузере. При недоступности видео использовать подписанные PNG review/compare/status; не называть их живым приложением. Нет визуальных доказательств — честно закончить демочасть, не изображать успешный запуск.
