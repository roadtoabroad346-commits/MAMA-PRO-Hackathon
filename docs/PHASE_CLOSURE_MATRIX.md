- `CORE`: React/TypeScript, S01–S03, каталог, matching на уровне offer, фильтры, профиль, сравнение, IndexedDB демозапросов, RU/KK.

В репозитории сохранены исторические PASS: TypeScript и 147 unit/integration, 79 CORE browser, 18 release browser, 5 pilot browser, 2 offline/map browser. В этой ветке **не запускались заново** браузерные проверки на физическом устройстве; GitHub Actions обеспечивает новый install/typecheck/unit/build, но не считает их PASSED до фактического результата.

## Формальные критерии закрытия каждой будущей фазы

1. Есть конкретный текст требований и источники, а не только номер.
2. Зафиксированы data contract, режим использования, владельцы и privacy impact.
3. Код добавлен на базе последнего подтверждённого коммита, без потери старых функций.
4. Есть прямые и отрицательные unit/integration/browser тесты, включая RU/KK, ошибку/отказ, доступность и восстановление.
5. Запущены типизация, сборка и применимые тесты; сохранены команды, среда, логи и SHA.
6. В traceability указан каждый AC: PASS / FAIL / NOT RUN / BLOCKED, без перевода NOT RUN в PASS.
7. Есть независимая проверка для критичных изменений и понятный rollback.
8. Человеческие приемочные действия подтверждены только реальными результатами, без фиктивных интервью/подписей.
9. Production изменения отдельно одобрены оператором и специалистами, если затрагивают семейные сведения.
10. Только после этого `completion_status` можно считать закрытым в новом отчёте (нынешний реестр вообще не использует такое поле).

## Отдельно об авторстве и хакатоне

До публикации или передачи организатору команда сверяет требования положения, происхождение предварительного кода, лицензионность материалов, согласия и факт участия родителя. Никакие GitHub-коммиты не заменяют этих подтверждений.
