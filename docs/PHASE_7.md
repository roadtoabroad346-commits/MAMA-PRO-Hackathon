# Фаза 7 — S04–S05

Дата: 07.11.2026. Основа: `phase-6-intake`, коммит `1e37808`. Рабочая ветка: `phase-7-search`. Реализация разрешена прямым запросом пользователя. Все сведения каталога остаются синтетическими. Облачные ресурсы, реальные обращения и публикация не создавались.

## Реализованное поведение

| Область | Реализация и доказательство |
|---|---|
| Один SearchInput | `Catalog.tsx` получает один синхронный SearchResult. Основной count, выбранные offer IDs, карточки, reasons/unknowns и chips относятся к его appliedInputSummary. Matching и группировка находятся в SearchService |
| Поиск | Имя и категория RU/KK, NFKC, пробелы, фиксированный locale-aware lower-case, ё/е. Казахские буквы не сливаются. Ограничение 80 символов; неподдерживаемая строка даёт 0 |
| Синонимы | Конечный словарь в SearchService: логопедия / сөйлеу терапевті / сөйлеу маманы → LOGOPED; дефектология / арнайы педагог → DEFECTOLOG; психология → PSYCHOLOG. Нет fuzzy/диагностического расширения |
| OR/AND | Категории соединяются OR, группы AND. Поиск и ограничения проверяются на одной услуге; O23/O24 не объединяются в вымышленную offline/KK-услугу |
| Карточка | Конкретная услуга, категория, язык, формат, район, цена/единица/длительность и дата цены, до трёх причин, неизвестные факты, объём проверки и ограничения. Числовых score/coverage, рейтингов и обещаний успеха в UI нет |
| Проверка | Схема сохраняет verificationFacts из имеющегося fixture: scope/status/evidence/date/limitations/synthetic. Отсутствующая проверка явно обозначена. Просмотр документа не становится общей гарантией |
| Сортировка | По соответствию, цене, району; выбранная услуга определяется тем же порядком. Exact/free перед from, stale/unknown в конце, ценовые ties по стабильным ID. У района известное несовпадение идёт перед unknown. При неактивном районе виден смысл fallback |
| S05 | Native dialog и мобильный bottom sheet. При открытии создаётся отдельная копия applied; preview считает SearchService. Apply одним update применяет нормализованный input и закрывает; Cancel/Close/Escape/backdrop ничего не применяют |
| Reset | В панели меняется только draft. В каталоге полный reset очищает query/условия/sort, сохраняет locale и comparison. Chips удаляют только соответствующее условие; удаление категории сохраняет остальные OR-значения |
| Ошибки бюджета | Невалидная сумма сохраняется в локальном draft, имеет inline-ошибку, блокирует Apply. Вместо ложного previewCount показана инструкция исправить сумму. 0 отличается от null |
| Empty | Честное отсутствие точных вариантов, объяснение AND-условий/текста, предложение изменить предпочтения и явные действия. Hard не ослабляется автоматически |
| Incomplete | SearchService возвращает отдельные incompleteItems/counts. Fail туда не попадает; специалисты с точной услугой повторно не добавляются. Список открывается отдельным действием и не увеличивает основной count |
| Loading/error | Зарезервировано место карточек. Загрузка/валидация JSON отличает ошибку от empty; общий каталог не подставляется вместо ошибки. Retry заново загружает и валидирует fixture, успешно восстанавливается после исправленного ответа |
| Сравнение | Tray появляется с первого выбора, показывает 1/3…3/3. При одном предлагает второго; четвёртый не заменяет выбранных. Пары specialist/offer фиксируются в памяти, замена услуги того же специалиста — отдельное явное действие |
| Профиль/возврат | Кнопка открывает выбранную услугу по публичной паре ID. Неверная пара даёт недоступную услугу без подмены. Возврат сохраняет applied, sort, comparison, scroll и фокус. Deep link показывает нейтральные сведения |
| Сравнение после изменения поиска | Фиксированные услуги остаются. Причины пересчитывает `SearchService.inspectOffer`, несовпадение явно обозначается. Смена одной сортировки не объявляется изменением условий |
| Доступность | Фокус ограничен native dialog и возвращается инициатору; если empty-кнопка исчезла после Apply, возвращается к «Фильтры». Прокручивается содержимое панели, footer остаётся доступным. RU/KK, reduced motion, мобильная и альбомная раскладки |

Фильтрация локальна и синхронна: старых асинхронных ответов фильтрации нет. Единственная асинхронная граница — загрузчик публичного каталога; App сохраняет guard active для устаревшего запроса/размонтирования. В fetch передаётся только локальный URL fixture, без SearchInput. Черновик панели не попадает в sessionStorage.

## Границы

Профиль и сравнение — работающие представления услуг, необходимые действиям каталога. Полный S06 с выбором всех услуг, S07 с переходом к заявке, S08–S09, IndexedDB и реальные обращения здесь не объявляются завершёнными; кнопок этих отсутствующих функций нет.

Comparison живёт в памяти текущего приложения; его сохранение после reload не обещается. Applied сохраняется существующим synthetic session snapshot, locale — отдельно. Экспертная редактура KK, исследование с родителем и аудит скринридером не проводились. Существующие документы фазы 0 остаются историческим планом.
