# Фаза 6 — S01–S03

Дата: 07.11.2026. Прямой запрос пользователя разрешает реализацию S01–S03. Старые ограничения мастер-промпта на подготовку документации относятся к предыдущей задаче. Внешних ресурсов, отправлений и публикаций не создано.

## Исходная точка

Удалённый `origin/HEAD` указывал на `2f9e111` (`phase-0-audit`). В нём только PROJECT_STATE, IMPLEMENTATION_PLAN, DECISIONS и REQUIREMENTS_TRACEABILITY. Других удалённых веток и исходников не обнаружено. Минимальные зависимости S01–S03 реализованы по ТЗ v1.0 §6–7/9/13/15/17 и принятым ADR-0002/0004–0009. Фазы 1–5 и полный P0 завершёнными не объявляются.

Созданы React/TypeScript/Vite-проект с lockfile, чистые контракты и SearchService, загрузчик валидируемого локального каталога, ru/kk, единый контекст параметров, ограниченное восстановление, S01–S03 и базовый `/specialists`. Последний поддерживает просмотр, имя/категорию и возврат к условиям. Полноценные S04–S09 остаются за рамками среза.

## Поведение и доказательство

| Область | Реализация |
|---|---|
| S01 | Название, ru/kk, демомаркировка, ценность, два клавиатурных входа без регистрации; `Home.tsx` |
| S02 | 4 шага; enum/возрастные диапазоны и бюджет 0…100000 из contracts; видимые label/legend, help, defaults, null/any, пропуск и сохранение при Back; `Intake.tsx` |
| Приватность | Нет имени ребёнка, диагноза, даты рождения, textarea, файлов и контактов. Strict schema отклоняет посторонние поля. Единственное текстовое поле анкеты — бюджет. Ответов в публичном URL нет |
| Обязательность | Возраст hard; выбранные язык/формат default hard, переключаемы; бюджет default soft, strict только явно. Район default soft, применим только при обязательном очном формате по ADR-0005; иначе сохраняется с пояснением |
| S03 | Summary строится из `SearchResult.appliedInputSummary`; значения и текстовые метки обязательности, редактирование каждого условия. Необязательный блок уточнения категории. Непустой поисковый query также показан |
| Count/переход | Review и каталог вызывают один `SearchService.search(input)`. Реальные specialist/offer counts и число неполных записей. Строгие условия автоматически не ослабляются |
| Язык | Typed словари, равенство ключей/плейсхолдеров, `html.lang`, locale отдельно от domain state. Заполненный KK-проход и смена языка внутри анкеты/review проверены |
| Reload | Synthetic session: schemaVersion=1, catalogVersion, TTL2h по runtime clock, input/step. Expired/corrupt/schema/catalog/enum mismatch очищают только ключ приложения с объяснением. Отказ чтения/записи/getter и localStorage не ломает память |
