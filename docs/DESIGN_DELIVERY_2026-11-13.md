# Поставка дизайна — 2026-11-13 (side-by-side compare + KK-даты Intl)

«вертикальная структура compare» и «KK-даты Intl».

## 1. Сравнение side-by-side (минор «вертикальная структура compare» закрыт)
- `Comparison` разбит на пять постоянных блоков: шапка, факты, соответствие,
  проверка, действия — `data-testid="comparison-card"` и все имена кнопок
  сохранены (тесты E2E не менялись).
- На экранах ≥1000px блоки выравниваются по строкам через CSS Grid **subgrid**
  (только внутри `@supports`; без поддержки subgrid карточки остаются
  обычными стеками — деградация безопасная).
- Точки карты и результат: сетка `auto-fit` — пустые треки схлопываются
  (2 карточки занимают 2 колонки, 3 — три).

## 2. KK-даты Intl (минор «KK-даты Intl» закрыт)
- `SavedDemo`: даты подтверждения цены (UTC-момент каталога) и сохранения
  (локальное время устройства) форматируются через `Intl.DateTimeFormat`
  с `dateStyle: 'medium'` в активной локали — сырые ISO-строки больше не
  показываются.
- `ResultMap`: даты подтверждения точек карты — `Intl` (UTC), локаль RU/KK.
- Пилотные поля: `input[type=date]` — высота 44px + акцент палитры;
  числовые поля — табличные цифры (`font-variant-numeric: tabular-nums`).
