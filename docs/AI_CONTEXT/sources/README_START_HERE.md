# MamaPro / Қолдау.Жол — Codex Expansion Package

**Комплект:** три документа для Codex/OpenCode и исходный Research. Срез подготовки: **13.11.2026**. Программа не развёрнута и не применена к GitHub автоматически — это инструкции для последовательной разработки.

## Какие файлы открывать

1. **`01_MASTER_IMPLEMENTATION_PROMPT.md`** — главный промпт. Скопируйте целиком в Codex/OpenCode, работающий в правильном checkout. Его `.docx` версия — для чтения и редактирования в Word.
2. **`02_CODEX_ENGINEERING_PLAYBOOK.md`** — практический инженерный гайд, шаблоны задач, тестов, отладки, восстановления контекста и правил Git.
3. **`03_INTEGRATED_PHASE_EXECUTION_PLAN.md`** — обязательная карта исполнения EXP-00–EXP-24, охват F000–F230 без пропусков, AC/тесты/блокеры, старые предложения 68–78.
4. **`00_REFERENCE_RESEARCH.docx`** — исходное исследование рынка, пользователей, всех функций и пустой раздел для реального родительского интервью.
5. **`FEATURE_REGISTRY_000-230.csv`** — машиночитаемый реестр функций.
6. **`STAGE_MAP.json`** — машиночитаемое распределение 231 ID по 25 стадиям.

## Минимальный запуск

1. Проверьте правильный GitHub repository: `https://github.com/roadtoabroad346-commits/MAMA-PRO-Hackathon`.
2. В Codex/OpenCode откройте папку репозитория и дайте доступ к этому комплекту (Markdown и Research Word). Не делитесь секретами `.env` и реальными семейными данными.
3. Вставьте мастер-промпт целиком и поручите **начать с EXP-00**; остальные два документа должны оставаться доступными агенту как спецификации.
4. Агент обязан создавать **отдельную feature-ветку**, коммитить и делать push после каждого завершённого проверенного slice, сверять локальный и remote SHA и сохранять `docs/expansion/STATE.json` + handoff.
5. Отдельное разрешение требуется для merge, production deployment, реальных контактов, реальных семейных данных и ослабления `LIVE_BLOCKED`. Этот комплект такого разрешения **не даёт**.
