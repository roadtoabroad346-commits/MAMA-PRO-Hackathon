# Часть 2 — 2026-11-12 (иконки, градиенты, визуальный район, чипы бюджета)

Продолжение по запросу владельца: иконки, сортировка, визуальный выбор районов,
удобный ввод сумм, градиенты вместо однотонных заливок.

## Изменения
1. **Набор инлайн-иконок** (`Icon` в `src/ui/controls.tsx`, §13.2 — без внешних ресурсов):
   поиск (leading icon в поле имени/категории), фильтры (кнопка «Фильтры»),
   карта (переключатель схемы), сегменты сортировки (реле/цена/район),
   пин района, «любой». Все `aria-hidden`, наследуют `currentColor`.
2. **Градиенты вместо однотонных заливок**: токены `--soft-grad`, `--accent-grad`;
   фон страницы (тёплая шапка-подложка), demo-notice, count-panel, verification,
   отмеченные выборы, прогресс-шаги, точки карты, активная вкладка пилота,
   верхняя акцент-линия карточек специалиста (teal→terracotta).
   Контраст сохранён: текст на градиентах — белый на teal ≥ 4.5:1, тёмный на светлых.
3. **Визуальный выбор района (анкета, шаг 4)**: `<select id="district">` →
   плитки на нативных radio (`name="districtId"`): «Любой» + 4 района с пинами;
   выбранная — градиентная, focus-visible — кольцо, hover — подъём.
   Обновлены 4 строки E2E (тот же контракт выбора); `#filter-district` в модалке
   фильтров остался нативным select (компактный контрол внутри модалки).
4. **Бюджет**: быстрые суммы-чипы 3 000 / 6 000 / 10 000 ₸ под числовым полем
   (в анкете и в модалке фильтров); клик подставляет значение и возвращает
   фокус в поле. Сам ввод не изменён — тесты `fill()` продолжают работать.
