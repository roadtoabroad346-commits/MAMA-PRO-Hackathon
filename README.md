## Запуск

Проверено на Node.js 24.22.1 и npm 11.9.0. Vite требует Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

Production-сборка и локальный просмотр:

```sh
npm run build
npm run preview
```

## Данные и состояние

Точные enum и ограничения находятся в `src/domain/contracts.ts`, каталог — в `src/data/catalog.json`. Это 12 вымышленных специалистов и 20 услуг из приложения A ТЗ v1.0. O10 нормализован по ADR-0008: дата источника цены равна `priceConfirmedAt`. Актуальность примеров считается от `demoClock`; TTL сессии — от реального времени.

Пустые ответы имеют значение `null`, категории — пустой массив. Бюджет `0` означает нулевой бюджет. Логические флаги имеют явные defaults контракта: выбранные язык/формат обязательны, бюджет/район — предпочтения, предпочтение готовности к обращению выключено. Язык интерфейса независим от языка занятий.

В `sessionStorage` сохраняется маркированный демопоиск со `schemaVersion`, `catalogVersion`, `expiresAt` и шагом; срок — 2 часа с начала сессии. Невалидный черновик суммы остаётся только в памяти; после reload восстанавливаются валидные параметры, некорректная сумма не становится нулём. `localStorage` содержит только locale. Ошибка хранилища оставляет работающий поиск в памяти с предупреждением. Ответы не попадают в URL, аналитику или запросы к серверу. Уведомления просят использовать только демонстрационные параметры.

## Граница среза

Фаза 6 дала основу S01–S03, контракты, каталог и SearchService; отдельных завершённых фаз 1–5 не было. Фаза 7 добавила S04–S05 и просмотр сравнения. Фаза 8 завершила S06: выбранная услуга определяет условия, объяснения, паспорт и переход `/request/:offerId`. Этот переход открывает проверяемое резюме точной услуги с честным текстом «не сохранён». Полные S07–S09, IndexedDB-сохранение демозапросов и реальные обращения не объявляются завершёнными.

Matching выполняется только в SearchService: точные и incomplete-кандидаты раздельны. Фильтрация синхронная; Preview и Apply используют тот же расчёт. Панель хранит отдельный черновик, который не попадает в sessionStorage. Сравнение фиксирует пары specialist/offer в памяти текущей сессии; сортировка и фильтры не удаляют их и не подменяют услугу автоматически. Возврат из профиля сохраняет выдачу, прокрутку и фокус. Каталог загружается как локальный публичный JSON с повторной валидацией при Retry; параметры поиска при этом не отправляются.

Палитра и размеры взяты из ТЗ §13. Шрифты системные, без внешней загрузки. Статичная SVG-ласточка создана в коде для этого среза, без внешних ссылок/скриптов. RU/KK-тексты программно проверены на полноту ключей и плейсхолдеров; редактура носителем и исследование с родителем не проводились.
